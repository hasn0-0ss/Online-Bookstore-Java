# 📚 Online Bookstore Management System (Java)
A Java-based Online Bookstore Management System using OOP concepts.

## 📖 Project Description

The **Online Bookstore Management System** is a Java-based console application developed as a university semester project. It allows users to manage books in a bookstore through simple and interactive menu-based operations.

This project demonstrates the practical implementation of Java programming concepts, Object-Oriented Programming (OOP), classes, objects, methods, ArrayList, and basic inventory management.

## ✨ Features

- **Add Book:** Add new books with details such as title, author, price, and quantity.
- **Display Books:** View all available books in the bookstore.
- **Search Book:** Search for a book by its title.
- **Buy Book:** Purchase books by entering the required quantity.
- **Delete Book:** Remove books from the bookstore.
- **Update Book:** Update existing book information, including author, price, and quantity.
- **Stock Management:** Automatically update available stock after purchases.
- **Price Calculation:** Calculate the total purchase price based on book price and quantity.

## 🛠️ Technologies Used

## ▶️ How to Run

1. Install Java JDK on your computer.
2. Clone or download this repository.
3. Open the project in VS Code.
4. Open the terminal inside the `src` folder.
5. Compile the program:

```bash
javac Main.java Book.java Store.java
```

6. Run the application:

```bash
java Main
```
